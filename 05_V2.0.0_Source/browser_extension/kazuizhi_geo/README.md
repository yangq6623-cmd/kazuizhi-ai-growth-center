# 卡嘴子 AI 国内 GEO 常驻执行器（R8-28 / #788）

此扩展只使用用户已登录的 Chrome 会话，按 30 秒闹钟唤醒并与本机 `127.0.0.1:8876` 通信。它不会把排队、页面打开、SUBMITTED 或本地模拟记为成功；只有从真实外部 HTTPS 页面捕获到回答后才回传 Evidence。

安装：打开 `chrome://extensions`，开启“开发者模式”，选择“加载已解压的扩展程序”，指向本目录。安装后点击扩展图标，执行“验证五平台登录”。出现验证码或登录失效时，扩展会保留并激活对应标签页，等待用户人工处理。

正常运行时不需要保留五个平台标签页；需要让 Chrome 在 Windows 登录会话中保持运行，并关闭电脑自动睡眠。Manifest V3 后台由 `chrome.alarms` 唤醒，状态保存在 `chrome.storage.local`。

## 2.2.2.804 修复说明
- 修复 content-agent.js 在 manifest 自动注入及 worker fallback 重复注入时的 `SELECTORS` 声明冲突。
- 当扩展运行上下文不可用时，避免无保护访问 `chrome.runtime.onMessage`。
- 后台仅在明确缺少消息接收端时才补注入一次，不再把所有消息错误视为缺少监听器。
- AI 页面只要 DOM 已可交互即可进入验证，不必等待第三方网站所有网络请求结束。
- 修复只涉及 Chrome 扩展，不改变本地 #801 后端、正式 Evidence 真实性门禁或账号授权。
- 更新扩展后，请刷新五个平台已经打开的网页，重新执行单条只读验证；`ready` 不是正式 Evidence。
