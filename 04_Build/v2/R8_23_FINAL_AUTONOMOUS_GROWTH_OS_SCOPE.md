# R8-23 Final Autonomous Growth OS

## Permanent product doctrine

R8-23 does not replace R7/R8-22, SEO/GEO, models, publishing, accounts, or evidence. It binds them into one 7×24 operating system for 卡嘴子本地维修综合服务平台.

1. **ChatGPT is the only strategic controller.** Boss sets goals/boundaries. ChatGPT owns analysis, prioritization, Mission, Controller Plan, review, and next-round decisions. R7 is scheduling/execution/audit infrastructure, not a second strategy brain.
2. **Two business growth engines remain first-class:** 本地维修 and 个人任务发布. SEO/GEO is a growth channel, not the whole product.
3. **Eight AI employees remain concrete work owners:** 市场情报员、SEO/GEO增长员、内容运营员、社媒运营员、短视频运营员、本地增长员、用户转化员、数据复盘员.
4. **Models and connectors are tools with explicit routing.** Local model handles high-frequency low-risk work; RTX 3060 handles eligible local GPU/image/video work; Doubao cloud augments complex generation/QC; public/search/social/server connectors execute only when trigger + readiness + authorization allow it.
5. **Do not force every connected capability every cycle.** Every capability must state: who owns it, when it is triggered, fallback behavior, and where its result/Receipt returns.
6. **Truth gates never weaken.** Model/local output is not external publication/search/GEO/business proof. Formal GEO still requires real external A/B Evidence. Search submission proves SUBMITTED only. Public publishing requires a verified public URL/Receipt.
7. **External authorization is graded L1→L4 by platform + account + action.** A configured connector never grants blanket posting authority. New/risky routes remain human gated; stable explicitly whitelisted low-risk routes may advance under audit.
8. **Funds remain permanently human-only.** Payment/refund/withdrawal/settlement/price/funds are outside autonomous execution.
9. **Business attribution stops at order.** Allowed outcome chain: site visit → mini-program visit → consultation → task → order. No money/amount/revenue/profit/ROI automation metric.
10. **7×24 means resilience, not just uptime.** One model/API/platform/channel failure must degrade locally, defer that capability, and continue the core Mission. Restart/recovery resumes the last valid Mission and queued work.
11. **Social rollout stays “one real platform first, then copy.”** Multiple connectors may be visible simultaneously, but a real Post ID/URL/Receipt closed loop must be proven before expanding autonomous execution to another platform.

## Canonical operating loop

Boss goal → ChatGPT → Command → Mission → Controller Plan → AI employee-owned Task → selected model/tool/connector → Receipt/Evidence → search/GEO/business feedback → ChatGPT review → next cycle.
