# R8-20 SEO/GEO 真实增长经营闭环 — 38项升级范围

目标：在 R8-19 Phase 1–3 的真实 Evidence、自动优化和复测基础上，把 SEO/GEO 推进到可长期自治运营的 90%–95% 目标区间。

## 范围原则

- ChatGPT 是总脑/控制器；豆包、本地模型和 AI 员工是执行层。
- GEO 正式成绩只认真实 A/B Evidence；普通云 API 与本地模型默认 C 级辅助。
- SEO 必须遵守 `GENERATED ≠ PUBLISHED ≠ SUBMITTED ≠ CRAWLED ≠ INDEXED ≠ RANKED`。
- 业务归因最多追踪到订单：官网访问 → 小程序 → 咨询 → 任务 → 订单。
- 本阶段不采集或展示成交金额、收入、利润、ROI。
- 固定 GEO50 继续作为长期不可随意修改的基准；动态问题池是增量发现层。
- Phase 2 的 1→3→10→50 实机放量，以及 Phase 3 的真实发布→真实复测闭环，属于现场验收，不计入38项代码功能。

- 业务漏斗：官网访问 → 小程序 → 咨询 → 任务 → 订单。

- 异常/风险提醒。
