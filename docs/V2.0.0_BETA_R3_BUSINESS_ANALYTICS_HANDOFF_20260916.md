# V2.0.0 Beta R3 business analytics handoff — 2026-09-16

## Scope

R3 restores items 6–10 in the original 20-item upgrade recovery plan:

1. User growth analysis
2. Order conversion analysis
3. Technician supply analysis
4. Leader promotion analysis
5. Channel effect analysis

The existing daily review, operation summary, tomorrow plan, review history and AI Memory remain available.

## Data truth policy

The historical local state and AI report were inspected before implementation. They contain real public-market research signals, but the business bridge reports `connected: false`; its zero values are disconnected placeholders. R3 therefore displays all five business analyses as not connected until a snapshot includes both a real source and an `as_of` timestamp.

Public search evidence is never counted as a mini-program visit, user, lead, order or completed job. The import endpoint accepts aggregate metrics only and rejects phone numbers, addresses, identity fields, secrets, tokens, payment data and refund data.

## Read-only input paths

R3 can read an explicitly configured `KAZUIZHI_BUSINESS_METRICS_PATH`, the established `C:\卡嘴子自动化\bridge\business_metrics.json`, or the historical local business metrics path. A verified snapshot imported in the dashboard is stored under the durable V2 data directory and survives reinstall/uninstall.

## API and interface

- `GET /api/business-analytics` returns the five analysis modules and connection status.
- `GET /api/business-metrics/template` returns the aggregate input contract with empty values.
- `POST /api/business-metrics/import` validates and stores a verified aggregate snapshot.
- The new 经营分析 page shows source, reporting time, module availability, conversion rates and channel attribution.

## Acceptance

With no verified snapshot, all five modules must say not connected and no zero may be presented as a real result. With a valid snapshot, derived conversion rates must match the supplied aggregates. Sensitive or financial-detail fields must return HTTP 400. Verified orders, users, active technicians, active leaders and promotion activity must feed the daily operation summary.

## Preserved baseline

The V1.9.5 Enterprise R3 branch `baseline/v1.9.5-enterprise-r3-20260915`, installer sources, historical documents and hashes remain unchanged. V2 review history, plans, summaries and AI Memory stay in the same durable data directory.
