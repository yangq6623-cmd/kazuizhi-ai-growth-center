# R7 Final 已知问题与范围

- 外部 AI 默认未配置。需要用户提供自己的兼容接口凭据并通过连接测试；ChatGPT 网页会话不会自动连接本机程序。
- 小程序、订单、用户、收益等真实业务数据和服务器 API 尚未提供。相关经营指标保持“未接入”；公开关键词只用于选题研究。
- 双向运营桥的本机同步目录、离线回退、指令去重、审批和回执已做自动测试；Google Drive、OneDrive 等实际云盘的端到端同步需要用户自行配置同步目录后再验收。
- 自动 Agent 执行、SEO/GEO 自动增长、自动发布与真实效果统计不在 R7 Final 的已验证能力内，属于交接文档列出的后续 R8 方向。
- 1–2 天连续运行与最终用户环境按钮验收尚需发布后的实际使用窗口；自动测试不能替代这两项观察。
