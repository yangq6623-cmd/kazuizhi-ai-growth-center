# 卡嘴子 AI V2.2.0 R8 Operational 使用说明

## 升级原则

- 直接覆盖安装，沿用原安装目录和原本地数据目录。
- 第一次启动会先复制旧任务、审计、运营记忆、经营数据、AI/同步桥、设备和账号资料，再写入 R8 新数据。
- 卸载程序不删除经营数据。
- 旧版已保存的 ADB 路径、最后设备、控制模式和账号档案会自动继承；授权已经被平台撤销时，才需要重新登录。

## 正常工作顺序

1. 在“增长战役”中选择区域、服务和真实用户问题，建立增长 ID。
2. 在“内容工厂”导入真实照片或视频；真实现场素材必须确认已取得拍摄与发布同意。
3. 创建视频任务，点击“3060 生成成片”。系统会生成竖屏片头、真实素材主体和行动提示，并优先使用 RTX 3060/NVENC。
4. 成片只进入“等待人工审核”；老板确认后才取得发布授权。
5. 已验证可发布的账号才能进入发布排期。验证码、人脸、安全锁和平台风险提示必须人工处理。
6. 只有保存平台内容 ID 和真实链接，系统才显示“已验证发布”。
7. 咨询、小程序需求、团长码、师傅报价和完成订单使用可验证数据回流；没有来源的数据不归因给 AI。

## 手机画面

- 手机通过 USB 连接并在手机上允许调试后，进入“手机与真机”。
- 点击“扫描手机”后会连续同步。只有完整有效的 PNG 才替换当前画面；一次读取失败会保留上一帧并自动重试。
- 单击电脑里的手机画面等于真机点击，拖动等于真机滑动。
- 密码、指纹、人脸、验证码和平台风控会停止自动操作并等待人工。

## 必须人工完成的事项

- 首次或失效后的平台账号登录、验证码、人脸和风险校验。
- 每一条对外视频的最终审核。
- 退款、提现、支付、改价、赔偿等资金动作。
- 用户明确同意后，才可转入微信或其他私域沟通。
- 官网站长平台、域名或服务器所有权验证。

## 当前视频能力边界

安装包内置短视频合成组件，可用真实素材完成竖屏适配、片头片尾和 RTX 3060 硬件编码。生成式视频模型权重通常为数 GB 至数十 GB，不随 GitHub 安装包捆绑；未安装权重时，界面会明确显示，不会假报“AI 生成成功”。
