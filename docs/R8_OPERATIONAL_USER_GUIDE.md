# 卡嘴子 AI V2.2.2 R8 Autonomous Mission Core 使用说明

## 升级原则

- 直接覆盖安装，沿用原安装目录和原本地数据目录，不需要先卸载旧版。
- 第一次启动会保留旧任务、审计、运营记忆、经营数据、AI/同步桥、设备和账号资料，再写入 R8 新数据。
- 卸载程序不删除经营数据。
- 旧版已保存的 ADB 路径、最后设备、控制模式和账号档案会继续继承；平台实际授权失效时，才需要重新登录。
- R7 与 R8 不再按“两套系统”理解：它们是同一个自治运营系统的老板视图和执行视图，共享 Mission、Growth ID、状态和结果回流。

## 日常只需要做什么

正常情况下老板只需要两类动作：

1. 给系统经营目标或确认当前经营方向；R7、ChatGPT 和 R8 会在同一个 Mission 中继续推进。
2. 在最终成片出现后选择“通过并发布 / 退回重做 / 暂不发布”。

验证码、人脸、异常登录、平台风险校验、资金动作和重大事实歧义仍由人工处理；其余市场分析、优先级、策划、脚本、素材路由、生产、技术质检、ChatGPT 内容质检、低风险调度和复盘由系统自动推进。

## 一条连续经营主线

系统统一按以下循环运行：

> 老板目标 → ChatGPT 总决策 → R7 分析/机会发现 → Mission → R8 执行 → 成片审核 → 平台发布 → 真实结果回流 → R7 复盘 → ChatGPT 下一轮决策

- 每个经营任务有唯一 `MISSION-*`，并关联 Growth ID、视频任务、发布计划和真实回执。
- R7 的经理判断、AI 员工提案和区域策略会进入同一 Mission 上下文，R8 不需要重新填写一次。
- R8 的真实执行状态和真实发布回执会回流 R7，供 ChatGPT 判断继续、停止或创建下一轮 Mission。
- ChatGPT 的 Mission 决策只允许低风险经营动作：继续、停止、创建下一轮经营任务；不能跳过老板最终审核、账号验证、资金和合规边界。

## 正常工作顺序

1. 在老板总控设置经营目标，或由 R7 从真实数据和运营任务中形成可执行增长方向。
2. 当一个增长战役准备好后，系统自动建立/同步 Mission，并可自动进入第一条 R8 视频生产任务，不要求老板再点一次“开始视频”。
3. **本地素材是可选增强，不上传照片或视频也不会阻塞生产。**有真实素材时可直接多选或拖入照片、视频、音频，系统自动识别、去重、索引和评分。
4. ChatGPT 自动完成选题细化、标题、深层脚本、分镜、素材选择和平台适配；本地 RTX 3060 / FFmpeg / TTS / 字幕等组件负责执行。
5. 系统自动合成候选成片并完成技术质检，再交给 ChatGPT 做成片内容质检；通过后生成可审核的 FINAL.MP4。
6. 老板只审核最终成片。通过后才取得发布授权；退回后系统按反馈自动重做，不要求人工编辑 EDL 或重新分类素材。
7. 账号发布资格是只读真实状态，不能通过下拉框或表单自行标记“已验证可发布”。只有真实手机在线、平台账号实际授权、风险状态正常时才开放发布。
8. 只有保存了可验证的平台内容 ID 和真实链接，系统才显示“已验证发布”。
9. 发布、咨询、小程序需求、团长码、师傅报价和完成订单只使用可验证数据回流；没有来源的数据不归因给 AI。
10. R7 再读取 Mission 真实结果，ChatGPT 决定继续、停止或建立下一轮 Mission，形成持续循环，而不是“一条视频做完就结束”。

## 两个控制台怎么理解

- **老板总控（R7）**：看经营目标、AI 判断、机会、优先级、经营结果和“待我处理”。
- **执行中心（R8）**：看内容生产、真机、平台、发布、SEO/GEO、咨询与订单执行状态。
- 两边顶部共享同一条“卡嘴子自治运营主线”，显示当前 Mission、区域/业务、当前阶段和真实人工阻塞。
- 用户不需要自己判断“这件事应该去 R7 还是 R8”；系统按任务阶段自动推进。

## 页面结构

- **今日总控**：只看当前目标、真实生产阶段、“待我处理”和经营结果状态。
- **统一 Mission 主线**：在 R7 和 R8 都可看到当前经营任务、老板目标、AI/R7 判断、R8 执行状态和时间线。
- **增长战役**：当前战役优先显示；新建战役默认收起，避免重复入口。
- **内容工厂**：主区域只突出“当前生产任务”和“待我审核”；RTX 3060、FFmpeg、队列等技术细节默认折叠。
- **终端与真机**：保留真实手机画面和常用操作；音量、旋转等高级控制放入“更多设备控制”。
- **账号与发布**：账号验证状态只读，登录与风控问题通过真实终端/后续官方连接器处理；没有真实验证不开放发布。
- **咨询与订单 / SEO/GEO**：继承当前 Mission / Growth ID，不要求每个页面重复选择。
- **系统体检**：人工事项和建设配置项分开显示，不把普通建设任务冒充成“待我处理”。

## 手机画面

- 手机通过 USB 连接并在手机上允许调试后，进入“终端与真机”。
- 点击“扫描手机”后会同步真机。只有完整有效的 PNG 才替换当前画面；一次读取失败会保留上一帧并自动重试。
- 单击电脑里的手机画面等于真机点击，拖动等于真机滑动。
- 密码、指纹、人脸、验证码和平台风控会停止自动操作并等待人工。

## 必须人工完成的事项

- 首次或失效后的平台账号登录、验证码、人脸和风险校验。
- 每一条对外视频的最终审核。
- 退款、提现、支付、改价、赔偿等资金动作。
- 涉及隐私、素材权利或重要业务事实且系统无法确认的事项。
- 官网站长平台、域名或服务器所有权验证。

## 视频能力边界

安装包内置短视频合成、字幕、音频处理和 FFmpeg 编码链路，并支持 RTX 3060/NVENC 路径与 CPU 回退。生成式视频模型或外部授权素材服务若需要独立权重、凭据或授权，不会因为缺失而阻塞整个任务；系统会按真实素材、授权素材、AI 辅助画面、信息卡等安全降级路径继续完成可审核视频。

没有真实维修过程证据时，系统不得用 AI 画面冒充真实维修案例、真实师傅操作或真实前后对比；需要时会明确使用“原理示意 / 情景演示 / AI辅助画面 / 图文解释”等形式。
