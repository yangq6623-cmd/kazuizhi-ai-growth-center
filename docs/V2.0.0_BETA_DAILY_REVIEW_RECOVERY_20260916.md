# V2.0.0 Beta 每日复盘第一批功能恢复交接

日期：2026-09-16。Build：`KZ-ENTERPRISE-V2-BETA-20260916-R1`。自动验证已通过，构建与校验值见 `V2.0.0_BETA_R1_BUILD_DELIVERY_20260916.md`。

## 本批恢复范围

按用户确认的位置完成以下模块：

1. AI 每日复盘中心：AI 任务 / 运营中心。
2. 今日运营总结：运营分析模块。
3. 明日计划：计划模块。
4. 历史复盘记录：数据记录模块。
5. AI Memory：AI 基础服务。

每日复盘中心把运营总结、问题分析、增长机会和明日计划串成一次可保存的复盘。
历史记录最多保留最近 365 次生成结果。AI Memory 支持保存老板手动确认的事实，并记录来源和时间。

## 数据位置和兼容策略

V2 数据保存在 `%LOCALAPPDATA%/Kazuizhi_AI_Enterprise_V2.0.0_Beta/data/`：

- `reviews/latest_review.json`
- `reviews/history.json`
- `plans/latest_plan.json`

- `memory/experiments.json`

数据位于安装目录之外，覆盖安装和卸载不会删除。R3 源码、安装目录、数据及保护分支不修改。
本批没有发现可直接导入的 V1.8.x 完整数据文件，因此不伪造历史记录；后续获得旧数据后再建立只读导入器。

## 真实性和安全规则

- 没有接入真实订单、用户、收入、师傅、团长和推广数据时，运营总结返回 `not_connected`，界面显示“尚未接入”。
- 公开市场信号不能计为订单、成交或收入。
- 明日计划仅生成 `proposal_only` 建议，不直接执行。
- 支付、退款、改价、提现、结算、充值、补贴、赔付和佣金打款永久列为人工处理。
- 当前低风险动作名称保持 `run_scan / add_priority_seed / add_owner_command`。
