# R7 Final 使用说明

安装文件：`Kazuizhi_AI_Enterprise_V2.0.0_R7_Final.exe`。运行安装程序后，从桌面“卡嘴子 AI 增长运营中心 V2 Beta R7 Final”启动；程序在本机打开 `http://127.0.0.1:8876`。左下角应显示 **V2.0.0 Beta R7 Final**，构建标识应为 `KZ-ENTERPRISE-V2-BETA-20260917-R7-FINAL`。

首次使用请打开“连接与体检”。本地引擎可离线使用；外部 AI 需要用户填写兼容接口地址、模型和 API 密钥并点击“测试连接”，只有通过真实端点验证才会显示“已连接”。经营数据需要导入带来源的真实快照。没有接入时，订单、客户、收入、效果均显示“未接入”，不会给出推测值。

在“任务与员工”创建任务后，先审批，再执行或记录人工完成结果。内容增长生成的是待审核草稿，不会自动发布。页面标题下方会持续显示操作结果；若按钮操作失败，请按提示检查输入和连接状态。

遇到端口占用或旧页面，请关闭旧版运行程序并重新启动 R7 Final，按页面左下版本和 `/api/status` 中的 `build` 字段确认当前程序。浏览器地址栏中旧的 `?build=` 参数不代表实际版本。
