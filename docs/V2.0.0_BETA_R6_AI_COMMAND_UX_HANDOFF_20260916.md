# V2.0.0 Beta R6 AI 指挥中心与产品体验交接

## 图片构想分析

参考图的核心不是单纯增加一个仪表盘，而是建立长期运行的 AI 经营系统：负责人提供战略方向，AI 运营总指挥协调数据分析、战略规划、内容增长和经营优化四类角色，最后通过“发现问题→分析原因→制定策略→生成任务→人工执行→获取结果→AI 复盘”形成闭环。

R6 将这个逻辑放入首页，但不会把未接入的服务伪装为已连接。

## R6 改造范围

- 首页升级为 AI 运营指挥中心，显示四类 AI 角色和七步运营闭环。
- 新增“连接与体检”页面，统一显示本地引擎、外部大模型、经营数据、云盘、发布和资金操作状态。
- 支持 OpenAI 兼容端点、模型和 API 密钥配置。
- API 密钥使用 Windows DPAPI 当前用户加密，不写入仓库、构建产物、JSON 配置或日志。
- 连接测试实际请求模型端点；只有通过连接和鉴权验证后才显示“已连接”。
- 新增 AI 运营问答入口，输出固定为待人工审核建议，不自动执行或发布。
- 新增系统体检，检查本机存储、前后端版本、本地 AI、外部 AI、经营数据和安全边界。
- 增加键盘焦点、禁用状态、响应式布局、中文状态和更明确的操作反馈。

## 真实状态规则

- 本地规则引擎可在离线状态完成复盘、分析、内容草稿和任务规划。
- 外部大模型未配置时必须显示“未配置”。
- 真实经营数据未接入时不展示占位 0 或推测数字。
- 云盘未授权时显示“未接入”。
- 内容发布保持人工审核；资金操作永久禁止自动执行。

## 验收要点

1. 确认首页显示 R6、四类 AI 角色和七步闭环。
2. 打开“连接与体检”，确认未配置的外部 AI 不会显示为已连接。
3. 点击“立即体检”，检查结果和待配置说明。
4. 使用专用测试密钥时，确认密钥不出现在界面响应、日志或 JSON 文件中。
5. 逐页测试导航、表单、生成按钮、复制、筛选、任务状态和历史记录。
6. 确认旧 R5 桌面快捷方式被替换，R3 稳定基线与历史文档保持不变。
