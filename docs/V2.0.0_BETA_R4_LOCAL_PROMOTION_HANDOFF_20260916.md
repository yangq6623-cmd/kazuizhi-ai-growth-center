# V2.0.0 Beta R4 本地推广 AI 验收说明

R4 恢复 20 项计划中的第 11–15 项：本地关键词库、SEO 内容生成、GEO 本地优化、AI 广告文案和 AI 短视频推广助手。

## 验收入口

启动后打开左侧“内容增长”。填写地区、服务、关键词，可分别生成四类草稿；生成记录会保存在本机。关键词可以手动增加，也可只读接收现有公开搜索研究信号。

## 真实性和执行边界

- 所有输出均标记为 `proposal_only` 和“待人工审核”。
- 程序不会自动发布、投放、发送消息或执行资金操作。
- 公开关键词信号只代表研究优先级，不代表搜索量、排名、订单或收入。
- 没有证据时不写订单量、排名、用户评价、成功案例或效果数字。
- 禁止“人人都能接单”“无需审核即可接单”“所有任务都能发布”等表述。
- 接单能力以平台实际开放、账号审核和任务状态为准；个人任务预算由发布者自主填写。

## 数据位置

关键词和生成历史保存在用户本机的 V2 持久数据目录中，升级和卸载测试不会删除这些数据。V1.9.5 Enterprise R3 稳定基线、交接文档和既有 V2 数据保持不变。

## 测试重点

1. “内容增长”页面能看到五个模块。
2. 新关键词保存后重新打开仍存在。
3. 四种草稿都能生成并进入最近记录。
4. 输入禁止宣传承诺时，服务返回拒绝。
5. 页面和结果明确显示“仅草稿，不自动发布”。
