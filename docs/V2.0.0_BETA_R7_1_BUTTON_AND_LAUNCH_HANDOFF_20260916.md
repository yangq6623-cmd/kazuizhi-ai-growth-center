# V2.0.0 Beta R7.1 启动与按钮验收

## 为什么用户看到了 R6

2026-09-16 检查本机时，`127.0.0.1:8876` 的进程 PID 2896 来自旧版解压目录 `C:\卡嘴子自动化\卡嘴子自动化\Kazuizhi_AI_Enterprise_V2.0.0_Beta_Setup （1）\Kazuizhi_AI_Enterprise_V2.0.0_Beta\`。本机默认安装目录中的程序版本为 2.0.0.5，桌面仍有 R6 快捷方式。用户展示的 GitHub 页面属于 V1.9.5 R3 稳定版保护构建，其 Artifact 也标明 V1.9.5；它不是 R7 安装包。

R7 正式安装包的 SHA256 和 CI 记录吻合，FileVersion 为 2.0.0.7。截图中的 R6 页面来自仍在运行的旧进程，而非 R7 程序启动后的画面。R7.1 安装程序会结束相同可执行文件名的旧进程、覆盖默认安装位置，并清理旧 R7 快捷方式。验收时需查看页面左下版本和 `/api/status` 构建标识，而不是只看浏览器地址栏的旧 `?build=` 参数。
