# 卡嘴智 R8 Final 自动化测试报告

## 覆盖范围

- R6 数据迁移与损坏保护。
- R7 持久化、任务引擎、双向桥、八员工、决策中心、区域策略和真实经营数据源。
- R8-00 安全边界与单真机试点。
- R8-01 ADB 设备中心、屏幕同步、文件传输和人工接管。
- R8 社媒账号矩阵、多账号、登录授权和单设备串行规则。
- R8-02 至 R8-08 完整增长闭环。
- 所有前端 JavaScript 语法和可见交互绑定。
- Windows 打包、静默安装、覆盖安装、运行中升级、用户数据保留和卸载。
- Final 安装器 Microsoft Defender 自定义扫描与 SHA-256 记录。

## R8 完整闭环用例

自动测试从真实公开信号开始，依次验证查重、唯一账号路由、增长 ID、八员工策划、人工审批、视频任务、老板发布确认、真实回执、统一消息、线索、订单归因、72 小时指标和学习回写。

负向用例包括：密码字段拒收、未确认禁止发布、没有内容 ID/URL 禁止成功回执、投诉退款自动进入人工处理。

## 通过标准

CI 中任一测试失败、安装器丢失、覆盖升级无法关闭运行程序、用户数据被修改、Defender 检出安装器或文件哈希记录失败，均不得发布最终安装包。
