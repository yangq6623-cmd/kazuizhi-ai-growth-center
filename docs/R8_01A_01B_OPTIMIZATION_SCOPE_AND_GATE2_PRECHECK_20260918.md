# 卡嘴子 R8-01A / R8-01B 优化锁定范围（Gate 2 前置）

日期：2026-09-18
分支：`codex/v2-r8-growth-ops`
基线：R7 Final 稳定底座 + R8-00 安全层 + R8-01 单真机试点

本文件是《卡嘴子 R8 总体升级实施与最终交付计划_20260918》的增量补充，不改变 Gate 顺序。R8-01 仍只验证 1 台真实 Android 手机；第一台通过 Gate 2 后才允许增加第二台。

## 1. R8-01A 配置永久保存

升级、覆盖安装和程序重启不能要求老板重新填写已经验证过的配置。

必须长期保存在安装目录之外的用户数据目录：

- 生产经营数据只读密钥：Windows DPAPI 加密保存；已保存时直接重新验证，不回显明文、不要求重复粘贴。
- 双向运营桥根目录：保存 `AI_Command` 配置；Google Drive 盘符从 G: 变 D: 等情况时，按同一相对目录自动恢复并更新配置，不清空旧配置。
- ADB 路径：自动发现后持久化。
- 最近真实设备 ID / 型号 / Android 信息：持久化用于恢复提示；在线状态仍以实时 ADB 为唯一真值。
- 社媒设备 / 平台 / 账号绑定：继续由 R8 持久化状态保存。
- 人工接管 / R8 / 暂停等运行模式：保存在设备运行状态中。

安全边界：密码、Cookie、Token 等平台凭证不得进入 GitHub、普通日志或 ChatGPT 对话；经营数据密钥只允许本机加密保存。

## 2. R8-01B 真机操作台

入口固定为：`社媒中心 → 设备矩阵 → 真机操作台`。

“连接与体检”只保留基础设施健康检查，不再承载第二套手机业务控制。

真机操作台目标：

- 右侧/主区域显示真实手机画面。
- 单击电脑端手机画面 = 真机点击。
- 鼠标拖动 = 真机滑动。
- 每次操作后自动重新抓屏。
- 返回 / Home / 唤醒 / 电源 / 刷新作为辅助操作。
- 文件传输、操作日志保留。
- 控制模式统一为：R8 自动 / 人工控制 / 暂停。

## 3. 屏幕状态必须拆分

禁止继续把“锁屏/熄屏”混成一个状态。

### 普通熄屏

- 允许安全自动唤醒。
- 普通操作到来时：先唤醒 → 重新检查状态 → 未锁定才继续原操作。
- 操作台覆盖层显示“点击自动唤醒”。

### 锁屏 / 安全验证

以下状态必须停止自动操作并转人工：

- PIN / 密码
- 指纹 / 人脸
- Android 安全锁
- 短信验证码
- 平台验证 / 异常登录 / 风控页

不得绕过验证。

## 4. 任务期间保持亮屏

- R8 任务运行期间可启用 USB 保持亮屏策略。
- 任务结束后恢复正常熄屏策略。
- 不允许把永久常亮作为默认系统设置。

## 5. Gate 2 前置完成判定

R8-01A + R8-01B 优化完成并重新生成安装包后，才开始 Gate 2 真机验收。

Gate 2 验收顺序：

1. 覆盖升级后配置不丢。
2. 手机稳定识别。
3. 实时屏幕可读取。
4. 屏幕直接点击可控制真机。
5. 鼠标拖动可映射滑动。
6. 文本输入（当前 ASCII 范围）。
7. 返回 / Home。
8. 普通熄屏自动唤醒。
9. 任务期间保持亮屏。
10. 安全锁 / 验证页自动停止并转人工。
11. 人工接管。
12. 交还 R8。
13. USB 拔线立即停止。
14. 重连后安全恢复。
15. 文件双向传输。
16. 所有动作审计。
17. 连续稳定运行。

全部通过后才标记 Gate 2 PASS，并进入 R8-02 平台情报雷达。

## 6. 当前开发原则

- 单真机试点，不提前扩多设备。
- ADB 在线状态必须真实，不伪造。
- 普通熄屏可恢复；真正安全锁转人工。
- 不实现绕验证码、人脸、平台风控或设备伪装逻辑。
- 保留 R7 Final 稳定底座；R8 设备异常不得拖垮普通 R7 数据页面。
