# R7 Final 升级说明

R7 Final 汇合 R7 的指挥中心、AI 员工与任务、连接状态、经营数据入口和运营分析，并纳入 R7.1 的按钮反馈与旧进程处理。安装器沿用 V2 Beta 默认安装位置，升级时会关闭同名旧程序并清理 R2 至 R7.1 的旧桌面快捷方式。

用户数据保存在本机应用数据目录，重装与卸载验证会检查数据未被删除。R3 稳定版源码和构建路径保持独立，不参与本安装包构建。此次 Windows 文件版本为 `2.0.0.9`，程序构建标识为 `KZ-ENTERPRISE-V2-BETA-20260917-R7-FINAL`。

安装前请结束正在编辑的任务和草稿，并保留已有本机数据备份。安装后从新的 R7 Final 快捷方式启动，并在“连接与体检”重新确认外部 AI 与业务数据状态。
