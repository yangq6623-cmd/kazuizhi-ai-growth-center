# V2.0.0 Beta R2 upgrade handoff — 2026-09-16

## Problem reproduced

The visible dashboard was still V1.9.5 Enterprise R2 because the legacy `Kazuizhi_AI_V1.9.5_Enterprise.exe` process owned port 8876. The desktop shortcut labelled V2 also targeted an older unpacked test directory.

## R2 repair

- The installer stops the exact legacy V1.9.5 executable and any running V2 Beta executable before replacing V2 files.
- Stale V2 and V2 R1 desktop shortcuts are removed. A new `卡嘴子 AI 增长运营中心 V2 Beta R2` shortcut targets the installed V2 executable.
- If another program still owns the configured port, the launcher exits with a clear Chinese message and no traceback.
- All runtime, frontend, installer and Windows version markers use `KZ-ENTERPRISE-V2-BETA-20260916-R2` / `2.0.0 Beta R2`.

## Preserved baseline

The V1.9.5 Enterprise R3 source, installer, historical handoff documents and branch `baseline/v1.9.5-enterprise-r3-20260915` are unchanged. Installation only stops its running process; it does not uninstall or delete the R3 baseline.

## Acceptance

Launch the new Chinese R2 desktop shortcut. The page must show V2.0.0 Beta R2 and include 今日复盘、运营总结、明日计划、历史复盘 and AI Memory. `/api/status` must report build `KZ-ENTERPRISE-V2-BETA-20260916-R2`.
