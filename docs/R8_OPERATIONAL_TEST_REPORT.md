# V2.2.0 R8 Operational 验收报告

## 自动验收门槛

- 新总控首页与 V2.2.0 构建身份一致。
- 覆盖安装前完整复制既有用户数据，重复启动不重复迁移。
- 原 R7 任务、审计链、同步桥、经营数据和运营记忆继续可读。
- 旧版 ADB 路径、设备控制模式和账号档案自动继承。
- 本地素材上传写入增长 ID 专属目录，中断上传不留下正式素材。
- 没有本地真实素材不能创建视频任务。
- RTX 3060 存在时优先使用 H.264 NVENC；没有 NVIDIA GPU 时回退 CPU 编码。
- 已实际生成 1080×1920 MP4，并自动进入“等待人工审核”。
- 没有真实成片文件不能通过视频审核。
- 未验证账号不能进入发布排期。
- 没有平台内容 ID 和真实 HTTP(S) 链接不能记录为发布成功。
- 手机截图必须是完整 PNG；同步失败保留上一帧并重试。
- 安全锁、验证码、人脸和平台风险校验不自动绕过。
- 静默安装、覆盖重装、端口冲突、卸载和数据保留通过自动测试。

## 本机硬件实测

- GPU：NVIDIA GeForce RTX 3060，12GB 显存。
- 驱动：596.49。
- 视频组件：FFmpeg，检测到 `h264_nvenc` 与 `hevc_nvenc`。
- 实际测试：本地素材 → 1080×1920 MP4 → 等待人工审核，闭环通过。

## 需要现场验收

- 当前测试时手机没有保持在线，因此安装包能验证“无设备”提示、ADB 发现、截图协议与重连逻辑；插入真实手机后还需完成一次画面、点击、滑动、安全锁恢复的现场验收。
- 抖音、快手、小红书、视频号的真实登录与发布必须由账号本人完成首次验证。
- 官网当前 `robots.txt` 与 `sitemap.xml` 尚未部署；需要站点服务器/发布权限后完成上线验证。
- 社媒平台内容是否成功发布，只以真实内容链接和内容 ID 为准。
