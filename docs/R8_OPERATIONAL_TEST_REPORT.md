# V2.2.1 R8 Productized 自动验收报告

## 自动验收门槛

- 产品化工作台与当前 R8 构建身份一致，覆盖安装后原 R7/R8 数据和配置继续保留。
- 原 R7 任务、审计链、同步桥、经营数据和运营记忆继续可读。
- 旧版 ADB 路径、设备控制模式和账号档案继续继承。
- 当前 Growth ID 在增长战役、内容工厂、账号发布、咨询订单和 SEO/GEO 之间统一。
- 同一个 Growth ID 已有活动生产任务时，前后端都禁止重复创建。
- **0 本地素材也能创建视频任务并进入 ChatGPT 规划；真实本地素材属于可选增强，不是生产前置条件。**
- 本地素材支持多文件导入并自动识别类型；中文文件名不会破坏真实扩展名。
- ChatGPT 生产合同能够进入本地执行队列，FINAL.MP4 经过技术质检与 ChatGPT 内容质检后才进入人工审核。
- 需要真实过程证据的镜头不会被 AI 生成画面静默冒充。
- RTX/NVENC 编码路径被打包；不可用时允许按规则回退 CPU 编码。
- 没有真实成片文件不能通过最终视频审核。
- 人工表单不能把普通账号写成“已验证可发布”；发布资格只从真实终端/平台控制层同步。
- 未验证账号不能进入真实发布排期。
- 没有可验证的平台内容 ID 和真实 HTTP(S) 链接，不能记录为“已验证发布”。
- 手机截图必须是完整有效 PNG；同步失败保留上一帧并自动重试。
- 安全锁、验证码、人脸和平台风险校验不自动绕过。
- “待我处理”只统计最终成片审核、登录/验证、达到自动恢复上限的异常等真实人工事项；SEO、数据接入等建设项单独显示。
- Windows 打包、Microsoft Defender 检查、静默安装、覆盖重装、端口冲突、卸载和数据保留纳入自动构建门槛。

## CI / 隔离环境能够证明什么

自动构建可以验证：

- R7/R8 回归不被破坏；
- 0 素材生产链可进入 ChatGPT 规划并自动执行到可审核视频；
- FFmpeg、NVENC/CPU 回退相关代码和打包资源存在并通过自动验收；
- ADB 来源设备状态、账号控制层、发布资格门禁和真实回执门禁按规则工作；
- 安装包可以完成静默安装、覆盖升级和卸载，同时保留持久化数据。

CI 为了验证账号发布资格，会在**隔离临时数据目录**里调用与生产相同的控制层函数，建立测试 Android 终端、记录 `source=adb` 的测试探测状态、登记测试平台账号并写入受控授权状态。该过程只证明规则和数据链路，不代表真实用户手机或真实平台账号已经通过现场验收。

## 仍需要用户电脑现场验收

以下事项不能由 GitHub Actions 代替：

- 用户电脑上的 RTX 3060 / NVENC 长时间运行稳定性与实际温度、驱动环境。
- 真实 Android 手机 USB/ADB 连接、画面同步、点击、滑动、休眠恢复和断线重连。
- 抖音、快手、小红书、视频号等真实账号首次登录、验证码、人脸、设备风控和授权保持。
- 真实平台发布后取得的内容 ID、真实链接及后续 24h / 72h / 7d 数据。
- 小程序、后台咨询、师傅报价、履约订单等真实经营数据接入和归因。
- 官网 `robots.txt`、`sitemap.xml`、结构化数据、实际部署、抓取、收录和 AI 引用观察。

## 验收结论规则

自动测试全绿只表示“代码、打包和隔离闭环达到现场测试条件”，不能冒充真实平台或真实经营结果已经发生。最终状态必须继续遵守：

> 未审核不发布；未验证账号不发布；没有真实内容 ID / URL 不标记已验证发布；没有真实经营来源不归因给 AI。
