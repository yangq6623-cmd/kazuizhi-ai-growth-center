## 1. R7 收尾后的统一结论

R7 的定位是“公司内部已经会工作”：内部任务、8 名 AI 员工、经理汇总、经营数据、区域作战、审计、安全边界和 ChatGPT 交接已经形成稳定底座。

R8 不再重复重做 R7，而是在冻结 R7 Final 的基础上增加“真实互联网执行层”，把系统升级为：

`真实平台数据 → 平台情报学习 → R7 八员工分析 → R7 经理形成任务单 → R8 生成图文/视频 → AI 质检 → 老板确认发布 → 自动择时/平台适配 → 真实发布与合规互动 → 咨询/小程序/订单 → 24h/72h/7 天归因 → 回写学习库与 R7 下一轮策略`

## 2. 已最终确认、后续不得反复讨论的产品原则

1. **先安全、再自动化。** R8-00 安全与总控底座必须先于平台自动执行。
2. **第一阶段只接 1 台真实 Android 手机。** 第一台完整闭环稳定后再开放第 2 台，不提前做群控。
3. **Windows 是 R7/R8 总控，Android 手机是真实外部执行终端。** 首次通过 USB + Android 官方 ADB 调试能力识别和授权。
4. **真实设备优先，不伪造环境。** 不伪造设备指纹、IMEI、Android ID、GPS、IP；不绕验证码/短信/人脸/平台风险验证。
5. **遇到验证码、人脸、异常登录、处罚、权限失效、设备掉线时自动停止并转人工。**
6. **老板日常只保留两个核心人工动作：**
   - 视频/关键内容最终确认发布；
   - 所有资金事项人工处理。
7. **资金边界永久不变。** 支付、退款、提现、结算、转账、改价、补贴、赔付等不允许 AI 自动执行。
8. **视频发布必须老板点击“确认发布”。** 未确认不得对外发布。
9. **官方 API 优先。** API 不覆盖、且平台规则允许的正常操作，再使用真实手机执行。
10. **不做批量刷屏、账号互刷、复制评论、虚构用户经历、伪造订单/评价。**
11. **内容质量优先于数量。** 宁可当天不发，也不发低质量内容；不把播放量作为唯一目标。
12. **所有真实增长动作必须可追踪。** 后续统一使用增长 ID 贯穿来源、假设、内容、发布、回执、效果、咨询/订单和结论。

## 4. R8-01 单真机最终功能范围

设备中心必须显示：

- 在线/离线状态；
- 设备唯一 ID；
- 型号；
- Android 版本；
- 电量；
- USB/ADB 连接状态；
- 当前平台；
- 当前账号；
- 当前任务；
- 最近操作；
- 风险状态；
- 当前是 R8 控制还是人工接管。

设备控制必须覆盖：

- 打开真机屏幕窗口；
- 刷新截图；
- 点击；
- 滑动；
- 文本输入；
- 返回；
- Home；
- 双向文件传输：电脑 → 手机、手机 → 电脑，固定使用 `/sdcard/Download/Kazuizhi` 安全目录；
- 暂停任务；
- 人工接管；
- 交还 R8；
- 断线自动停止；
- 锁屏/熄屏时停止普通设备动作；
- 重连后从安全位置恢复，不重复高风险动作；
- 全动作审计：时间、设备、账号、任务 ID、动作、结果。
