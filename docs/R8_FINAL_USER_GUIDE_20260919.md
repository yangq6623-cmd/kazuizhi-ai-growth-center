# 卡嘴智 R8 Final 使用指南

## 第一次使用

安装后先打开“社媒中心”，用 USB 连接已开启调试授权的 Android 手机。看到设备在线后，添加平台账号；系统不保存平台密码、验证码或 Cookie，首次登录、扫码、人脸和异常验证都在真实手机 App 内人工完成。

## 日常工作入口

打开左侧“R8 增长总控”，按以下顺序使用：

1. **情报雷达**：录入带来源链接或来源 ID 的真实公开需求。
2. **内容委员会**：建立增长 ID，由八类 AI 员工形成可审核内容方案。
3. **3060 视频工厂**：配置本地 Worker 后生成镜头候选；未配置时任务会如实等待。
4. **审核与发布**：老板确认后进入队列；真实发布后回填内容 ID 和 URL。
5. **消息与线索**：把真实评论/私信汇入会话，建立线索并关联已核验订单。
6. **归因与学习**：录入 24h、72h、7天指标，生成下一轮调整。
7. **审计与体检**：查看来源、判断、审批、执行和回执记录。

## 自动化等级

- L1：只观察和收集公开信号。
- L2：默认级别，外部互动需老板确认。
- L3：可在安全边界内执行已批准的低风险互动。
- L4：仅为已完成专项验收的 Connector 预留；资金、验证码、人脸、风控和视频最终发布仍不能越过人工边界。

## 什么时候必须人工处理

支付、退款、提现、结算、改价、充值、补贴、赔付、佣金打款，以及验证码、短信、人脸、异常登录、投诉、纠纷和法律问题，全部转人工。

## 状态怎么看

“软件已就绪”代表功能代码与本地数据链路已交付；“上线待配置”代表还缺真实设备、账号授权、平台 Connector、GPU 模型或经营数据。两者分开显示，避免把演示状态误认为线上成功。
