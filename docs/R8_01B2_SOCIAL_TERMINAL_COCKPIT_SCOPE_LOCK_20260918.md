# R8-01B.2 社媒终端驾驶舱范围锁定（2026-09-18）

## 状态
本文件为 Gate 2 前最后一轮 UI / 交互优化范围锁定。除阻断性缺陷、安全问题和已确认验收失败外，本轮不再继续扩大功能范围。完成本轮后直接进入 Gate 2 真机验收。

## 产品定位
将当前“真机操作台”从设备调试面板升级为“AI 社媒终端驾驶舱”。

核心原则：
- 手机是执行终端，不是整个产品的信息中心。
- 平时优先展示任务、平台、账号、风险和是否需要人工处理。
- 设备 ID、Android、ADB 路径等技术字段收进折叠详情。
- 单手机多平台串行，多手机未来并行；Gate 2 仍只开放 1 台真实 Android 真机。
- 不实现规避验证码、人脸、PIN、平台风控等能力。

## 本轮锁定范围

### 1. 页面整体布局
- 压缩顶部说明区，减少长期占用空间的大段说明。
- 终端详情采用“手机实时画面 + 右侧任务驾驶区”的双栏主布局。
- 手机画面宽度约占 55%–60%，右侧运营信息约占 40%–45%。
- 尽量在 1080P 屏幕下完成主要操作，不依赖长页面滚动。
- 文件、日志、设备详情采用折叠 / 抽屉 / Tab，不再长期占据主页面。

### 2. 平台 Dock 与官方图标
在终端顶部增加平台 Dock：
- 抖音
- 小红书
- 快手
- 视频号
- 微博
- B站
- 其他平台

要求：
- 使用清晰的平台图标作为主要识别元素。
- 同时显示账号别名和状态角标。
- 当前平台高亮。
- 已登录、执行中、等待、待人工、未配置使用统一状态颜色。
- 平台图标不是装饰，点击后切换该终端的平台上下文。

### 3. 当前上下文条
顶部固定显示：
- 手机名称 / 型号
- 当前平台
- 当前账号
- 当前任务
- 任务进度
- 已运行时间
- 下一步动作
- 控制权
- 风险状态

目标：老板一眼知道“这台手机正在做什么、为什么、下一步是什么”。

### 4. 手机实时画面
- 手机画面继续作为主要人工操作区。
- 单击 = 真机点击。
- 鼠标拖动 = 真机滑动。
- 操作后自动刷新画面。
- 支持适应窗口 / 75% / 100% / 全屏。
- 双击或显式按钮可进入全屏人工控制。
- 保留返回 / Home / 刷新 / 唤醒 / 电源等快捷操作。

### 5. 屏幕与安全状态
必须区分：
- awake：亮屏 / 可操作
- screen_off：普通熄屏，可安全唤醒
- keyguard：锁屏界面，需要人工确认
- secure_lock：安全锁定，需要人工

规则：
- 普通熄屏：点击画面或普通操作前自动唤醒并重新检查。
- PIN / 密码 / 指纹 / 人脸 / 验证码 / 平台安全验证：停止自动化并转人工。
- 任务期间可保持亮屏，任务结束恢复正常熄屏策略。

### 6. 控制模式
统一为三种：
- R8 自动
- 人工控制
- 暂停

人工模式下固定提供“交还 R8”。
暂停模式不得继续普通自动操作。

### 7. 右侧任务驾驶区
右侧主区域分为 4 个 Tab：
- 任务
- 平台
- 人工处理
- 日志

任务 Tab：
- 当前任务
- 下一任务
- 今日完成
- 预计剩余时间

平台 Tab：
- 本机绑定的平台账号
- 登录 / 授权 / 风险 / 等待状态

人工处理 Tab：
- 登录过期
- 验证码 / 人脸 / 安全锁
- 视频待老板确认发布
- 高风险互动
- 高意向线索

日志 Tab：
- 最近动作
- 点击 / 滑动 / 唤醒 / 接管 / 文件等审计记录
- 默认只显示最近 5 条，支持查看全部

### 8. AI 决策说明
显示当前动作的可解释原因，例如：
- 内容相关度
- 为什么继续看
- 为什么快速跳过
- 为什么读取评论
- 提取了哪些用户需求信号

该能力用于可解释运营，不用于规避平台检测。

### 9. 今日运行链 / 平台时间线
显示同一手机当日串行平台顺序：
抖音 → 小红书 → 快手 → 视频号 → 微博 → B站

状态至少包括：
- 已完成
- 执行中
- 等待
- 待人工
- 已暂停

### 10. 终端健康度
提供聚合健康状态：
- 设备
- ADB
- 屏幕
- 平台账号
- 同步
- 风险
- 当前任务

界面状态统一中文化，不直接暴露 unknown / secure_lock 等内部状态码。

### 11. “需要我处理”老板待办
社媒中心顶部提供统一入口：
- 需要重新登录
- 安全锁 / 验证
- 内容待发布确认
- 手机离线
- 高风险事件
- 高意向线索待人工

原则：AI 能自行处理的事情不打扰老板；真正需要人工时才进入待办。

### 12. 内容与线索关联
终端上下文保留后续接口位置：
- 当前内容资产：标题 / 视频 / 封面 / 文案 / 标签 / CTA / 审核状态
- 当前消息 / 评论 / 私信 / 线索
- 高意向咨询可转线索池

本轮以 UI 和数据接口占位为主，不提前扩大到 R8-05 / R8-07 的完整发布闭环。

### 13. 多终端监控模式预留
本轮只做 UI / 架构预留，不开放第二台执行。

未来多终端模式：
- 多台手机使用小卡 / 小屏监控
- 点击某台手机展开完整终端驾驶舱
- 单手机平台任务串行
- 多手机并行

## 配置持久化继续作为前置要求
R8-01A 的配置永久保存规则继续有效：
- 经营数据只读密钥复用本机加密存储
- 双向桥 AI_Command 路径长期保存
- Google Drive 盘符变化自动恢复
- ADB 路径持久化
- 最近设备信息持久化
- 社媒设备 / 平台 / 账号绑定持久化
- 覆盖安装 / 升级 / 重启不得清空配置

## 本轮明确不做
- 不开放第二台真实手机执行
- 不进入 R8-02 平台学习正式运行
- 不做低延迟视频流 / scrcpy 级镜像
- 不绕过任何 PIN / 指纹 / 人脸 / 验证码 / 平台风控
- 不自动执行资金操作
- 不自动发布需老板最终确认的视频内容

完成 R8-01B.2 后，停止继续扩 UI 功能，进入 Gate 2 真机验收：

2. 真机识别稳定
3. 实时屏幕
4. 点击
5. 拖动 / 滑动
6. 文本输入
7. 返回 / Home
8. 普通熄屏自动唤醒

14. 重连恢复

17. 连续稳定运行
