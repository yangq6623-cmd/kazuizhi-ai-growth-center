## 二、#70 暴露出的最终缺口

`确认全部镜头并生成完整视频` 在 #70 只创建 `完整成片合成` 任务，没有真正执行：

- 自动选片兜底
- 最终时间轴
- 1080P 级输出
- 30fps 补帧
- 配音
- 字幕
- FFmpeg 剪辑
- 最终 MP4 技术质检
- 平台最终成片播放器 / 保存 / 打开文件位置

因此 #70 中“完整成片合成”状态不等于已经生成最终 MP4。

## 三、#71 目标

#71 必须直接复用 #70 已生成并已选择的镜头候选，禁止要求用户重新生成候选。

生产顺序：

`读取 #70 项目 → 正式镜头检查 → 人工选择优先 → 未选镜头自动选择真实可播放候选 → 30fps 帧率处理 → 1080P 级标准化 → FFmpeg 时间线拼接 → SRT 字幕 → 本地 TTS → 音频封装 → 完整解码质检 → FINAL_1080P_30FPS.mp4`

### 质量策略

- 目标交付：1080×1920（9:16）/ 1920×1080（16:9）/ 1080×1080（1:1）
- 帧率：30fps
- 优先使用 FFmpeg `minterpolate` 做运动插帧；不兼容时回退标准帧率转换。
- 插帧在原始小分辨率阶段执行，再做 1080P 标准化，避免在 1080P 上做昂贵运动估计。
- 画幅不匹配时使用模糊背景 + 原画面居中，不强行裁掉主体。
- 使用高质量编码参数；NVENC 可用时优先 NVENC。
- 480P/512 源转 1080P属于“交付清晰化/标准化”，不能伪称恢复了原本不存在的真实细节。

## 四、选片规则

1. 用户已经点“采用”的候选拥有最高优先级，系统不得覆盖。
2. 某正式镜头没有人工选择时，#71 才执行自动兜底选片。
3. 自动兜底只从真实存在、可读取的候选文件中选择。
4. 当前 #71 首版自动兜底以真实文件完整性和编码质量为主；后续可继续增加 Qwen-VL 语义画面评分。
5. 备用候选未全部生成，不阻塞已满足每镜头一个可用候选的最终成片。
