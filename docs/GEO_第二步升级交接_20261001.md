# 卡嘴子 AI · GEO 第二步升级交接文档

版本：R8-19 GEO Phase 2 · 2026-10-01

## 一、当前阶段

第一步 30%→50% 已完成架构与真实验证能力建设；第二步正式进入 50%→70%：分析、比较、ChatGPT总脑解释。

本阶段原则：
- A/B Evidence 才进入正式GEO分析。
- C级本地模型结果只能辅助，不进入正式指标。
- 确定性规则负责事实提取和比较。
- ChatGPT负责解释、候选行动和下一决策。
- 候选行动不会自动变成执行任务。
- 第三步的自动诊断、自动派任务、发布、复测暂不启动。

## 二、第二步本次已完成

### 1. Evidence 自动解析

新增 'core/geo_analysis.py'：
- 品牌是否出现
- 品牌出现次数
- 是否形成明确推荐
- 推荐信号与推荐位置
- 官网是否被引用
- 引用URL与来源域名
- 服务关键词匹配
- 第三方来源数量
- 逐题可见度分
- 逐题缺口
- 平台/竞品候选识别

### 2. GEO 结果聚合

新增 GET '/api/r8-19/geo/analysis'。
自动输出：A/B已分析题数、品牌提及率、明确推荐率、官网引用率、平均逐题可见度，以及自然发现/商业推荐/品牌认知三类分组。

### 3. GEO 缺口 Top10

自动形成：未提及品牌、商业题未形成推荐、提及但未引用官网、没有可追溯来源、品牌题能力信息不足。

缺口只从真实A/B结果生成。

### 4. 平台/竞品候选矩阵

系统记录回答中明确出现的平台名称。默认候选：58同城、美团、大众点评、闲鱼、百度地图。

这些名称默认只标记为候选平台，不自动认定为正式竞品；正式竞品判断仍交给 ChatGPT 总脑。

### 5. ChatGPT 分析包

新增 GET '/api/r8-19/geo/analysis/brief'，用于把确定性分析结果交给 ChatGPT 总脑。

### 6. 可选 ChatGPT 总脑分析器

新增 'integrations/geo_chatgpt_analyzer.py'。
接口：GET '/api/r8-19/geo/analysis/chatgpt'；POST '/api/r8-19/geo/analysis/chatgpt/run'。
仅使用已经产生的A/B Evidence分析包，不使用本地模型作为正式证据，不执行网页搜索，不改变Evidence、不改变正式GEO指标、不直接执行候选行动。API未配置时保持关闭，不影响网页真实GEO验证。

## 七、第三步

第二步达到稳定后，才进入 70%→80%：诊断 → 派任务 → 执行 → 发布回执 → 复测。

第三步包括自动发现GEO缺口、ChatGPT生成候选任务、内容/页面优化、执行中心执行、真实发布回执、再次GEO测试、前后效果比较、SEO + GEO 联合优化。

第三步目前禁止提前自动执行。

## 八、最终架构

老板目标 → ChatGPT总脑 → Mission / Decision / Command → GEO真实测试 → A/B Evidence / Receipt → 确定性分析与比较 → ChatGPT总脑解释 → 候选行动 → 第三步执行中心 → 真实发布回执 → GEO复测 → ChatGPT总脑再次判断。

本地模型始终只是辅助分析/生产层，不拥有总控权，也不能把自己的结果计入正式GEO成绩。
