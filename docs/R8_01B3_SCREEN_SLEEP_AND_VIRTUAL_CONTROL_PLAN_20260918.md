# R8-01B.3 屏幕休眠与虚拟控制面板（2026-09-18）

## 当前测试机事实登记
- 当前 Gate 2 测试手机：FIO-BD00。
- 当前测试手机未设置 PIN / 密码锁。
- 普通熄屏后，只要唤醒屏幕即可进入可操作状态，不需要人工在实体手机上解锁。
- 因此当前测试机的正常流程应为：熄屏 → R8 自动唤醒 → 重新抓屏 → 恢复电脑端手机画面 → 继续操作。
- 不应要求老板每次手工点实体手机才能恢复控制。

## 安全边界
以上仅登记当前测试机特性，不取消系统通用安全边界：
- 未来其他设备若存在 PIN / 密码 / 指纹 / 人脸 / 验证码 / 平台安全验证，必须停止自动化并转人工。
- 不实现绕过安全锁、验证码、人脸、平台风控的能力。

## R8-01B.3 必须完成
1. 电脑端手机画面作为主控制面板。
2. 鼠标单击 = 真机点击；鼠标拖动 = 真机滑动。
3. 普通熄屏时，不判定为不可操作：先自动唤醒，再重新抓屏并继续。
4. 手机中途自动熄屏时，R8 应自动恢复，不需要人工触碰实体手机。
5. 任务开始时动态开启保持亮屏；任务结束恢复手机正常熄屏策略，而不是长期常亮。
6. 平台快捷入口在操作前先检查：设备在线 → 屏幕状态 → 必要时唤醒 → 再打开对应平台。
7. 黑色手机画面在熄屏时显示明确覆盖层："手机已熄屏，点击自动唤醒"，而不是让用户误以为连接失效。
8. 自动唤醒后必须重新获取屏幕状态和最新截图，不能基于旧画面继续点击。
9. USB 断线、设备离线时立即停止普通自动动作。
10. 所有唤醒、点击、滑动、平台启动、接管和恢复动作进入审计日志。

## 当前目标
完成本项后，不再继续扩展 Gate 2 前 UI 功能，直接进入 Gate 2 真机验收。
