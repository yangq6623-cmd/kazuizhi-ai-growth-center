# V2.0.0 Beta R5 运营闭环与体验升级验收说明

R5 恢复原始 20 项计划中的第 16–20 项：AI 任务管理、AI 推广日历、AI 竞争分析、AI 客户需求分析和 AI 运营驾驶舱。至此，20 项恢复计划全部进入 V2 独立源码。

## 体验升级

- 新增运营驾驶舱作为首页，集中显示任务、草稿、关键词、推广日历和数据可信状态。
- 重新设计侧边栏、顶部导航、卡片层级、颜色、间距、空状态和移动端布局。
- 关键词支持搜索、来源筛选和点击套用；技术来源名称改为中文。
- 内容表单增加必填提示、清空、友好错误信息、结构化结果和复制按钮。
- 任务可设置优先级、日期和状态；推广日历可一键生成未来 7 天安排。
- 竞争分析只接受人工提供的可核验观察；客户需求分析明确区分公开信号和真实经营数据。
- Windows 程序改为无黑色控制台窗口运行；端口冲突仍会显示清晰提示。

## 安全与真实性

任务和推广日历不会自动执行；竞争报告和内容草稿均为待人工审核建议。公开关键词不代表客户数、订单、收入、排名或市场份额。资金相关操作继续永久由人工处理。

## 验收重点

1. 启动后不再长期显示黑色运行窗口。
2. 首页显示“运营驾驶舱”和“功能恢复 20 / 20”。
3. 新建任务、更新状态和刷新页面后数据仍保留。
4. 生成 7 天推广日历并在驾驶舱显示已安排天数。
5. 竞争观察和客户需求页面能生成结果，并保留真实性说明。
6. 内容增长页使用中文来源标签，可搜索、筛选、套用和复制结果。
